Spec Brief

Build an end-to-end encrypted bridge so a native Android app can watch local Claude Code sessions on this MacBook, receive pushes when one needs input or finishes, reply into a named session, and approve flagged tool permissions.

Canonical spec: spec.md. Resolved decisions D1-D11 live there and are not reopened during build.

Non-negotiable invariant: hooks fail open. With the bridge stopped or the network down, sessions must run normally with no added latency.

Target repo: /Users/shivamhl/Shivam/Remote-claude (currently empty, not yet a git repository).
